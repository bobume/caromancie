## 🔄 Carole — Synchronisation avec GitHub

**Avant chaque session de travail :**

1. **Première fois** → ouvre le terminal dans VS Code (`Ctrl + \``) et tape :
   ```
   git pull
   ```
   Cela rapatrie tout, y compris le script de vérification.

2. **Sessions suivantes** → lance le script avant de commencer :
   ```
   outils\windows\verifier-synchro.bat
   ```
   Ça vérifie qu'on est bien synchronisés et évite les conflits.
