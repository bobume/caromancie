# Caromancie.be

- Astro statique + Tailwind CSS 4 + TypeScript ; hébergement Cloudflare Pages.
- Budget minimal. Préférer du HTML généré et du JavaScript ciblé.
- Conserver une expérience simple pour Carole qui travaille sur Windows.
- Avant modification : lire `git status`, conserver les changements non liés.
- Vérifier les changements avec `npm run check` puis `npm run build`.
- Ne pas inventer d'interprétations attribuées au PDF, de tarifs ou de témoignages.
- Ne pas déposer le PDF ni de données privées dans ce dépôt public.
- Référence historique : `backup/avant-refonte-2026-10-20`.
